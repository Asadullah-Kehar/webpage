Faculty website — ready-to-upload package
========================================

Files included:
- index.html
- css/style.css
- data/publications.json
- images/profile.jpg (placeholder)
- files/CV.pdf (placeholder)
- files/publications/example-paper.pdf (placeholder)
- files/teaching/CS101-slides.zip (placeholder)

What to replace:
- Replace images/profile.jpg with your real profile photo (recommended size ~ 400x400).
- Replace files/CV.pdf with your actual CV PDF.
- Put real publication PDFs in files/publications/ and update data/publications.json accordingly.
- Update contact email and other text inside index.html as desired.

How to preview locally:
- Open a terminal in this folder and run:
    python -m http.server 8000
  then open http://localhost:8000 in your browser.

How to deploy to GitHub Pages:
- Create a new GitHub repo and push all files to main. Enable Pages in repository settings.

If you want me to customize the template with your real bio, photo and publication list, paste them here and I'll update the package for you.
